## About this site

This repository hosts my portfolio, built with React, TypeScript, Vite, Tailwind CSS and Framer Motion, styled after Microsoft 365's Fluent 2 design. Every push to `main` is deployed to GitHub Pages by `.github/workflows/deploy.yml`.

```bash
npm ci        # install dependencies
npm run dev   # start the local dev server
npm run build # type-check and build to dist/
```
